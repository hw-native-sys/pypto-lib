# DSV4.1 Flash A3 W8A8 experiment publication

This branch publishes the A3 W8A8 implementation and the experiment's textual
stage evidence, including reports, metadata, manifests, receipts, source plans,
and coordination records.

The branch intentionally excludes local virtual environments, compiler output,
shared-library binaries, raw tensor capsules, checkpoint payloads, and log or
metadata files larger than the publication threshold. Those files are machine
local artifacts and are not suitable for ordinary GitHub storage; their hashes
and bounded results are retained in the published reports where available.

The primary published milestone is configurable TP8/EP16/DP2 real-text
validation. The TP4/DP4/EP16 default implementation and its historical evidence
remain included in the source and experiment records.
